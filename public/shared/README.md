# 共享数据快照与云端设置（public/shared/）

本目录存放两类共享文件：

1. **共享数据快照**（`data-latest.xlsx`）：工程师在站点「系统设置 → 数据库备份 → 拉取共享数据」
   即可一键拉取此处发布的权威数据集（拉取会替换浏览器本地全部数据）。
2. **云端共享设置**（`settings.json`）：统计口径与默认收件人的团队共享配置，
   由「系统设置 → 云端共享设置」推送自动生成，工程师打开页面时自动拉取，
   无需手动操作（也可在设置页手动「立即拉取」）。

## 数据快照发布流程（维护者）

1. 在本系统「系统设置 → 数据库备份 → 导出备份」，得到 `器件验证数据备份_YYYYMMDD_HHmm.xlsx`
2. 将该文件重命名为 `data-latest.xlsx`，放入本目录（覆盖旧快照）
3. 提交并推送到 main 分支，GitHub Actions 自动重新部署站点，快照即生效

## 保密提示

本仓库为公开仓库：**放入本目录的快照对外网任何人可见、可下载**。
快照内含批次号、器件参数与报告文字等真实数据——若数据涉密，请勿发布到此处，
改用私下分发备份 xlsx（对方「导入备份」）的方式协同。
